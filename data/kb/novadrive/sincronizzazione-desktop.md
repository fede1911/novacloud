# Sincronizzazione dell'app desktop

## La cartella non si sincronizza
1. Controlla l'icona di NovaDrive nella barra delle applicazioni: se è grigia, l'app è in pausa.
   Clicca sull'icona e scegli **Riprendi sincronizzazione**.
2. Verifica di avere spazio disponibile: con lo spazio pieno la sincronizzazione si ferma.
3. Esci dall'app e riaprila. Se il problema resta, scegli **Impostazioni > Account > Disconnetti**
   e accedi di nuovo con le credenziali NovaID.
4. Aggiorna l'app all'ultima versione da **Impostazioni > Informazioni > Verifica aggiornamenti**.

## File non sincronizzati
Alcuni file non vengono mai sincronizzati:
- file più grandi di 50 GB;
- nomi che contengono i caratteri \ / : * ? " < > |;
- file temporanei che iniziano con ~$ o terminano con .tmp.

## Sincronizzazione lenta
La velocità dipende dalla connessione. Da **Impostazioni > Rete** verifica che non sia attivo un
limite di banda. I file grandi vengono caricati a blocchi: la barra di avanzamento può restare
ferma per qualche minuto senza che ci sia un errore.
