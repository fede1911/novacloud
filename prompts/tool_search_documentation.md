# Ricerca nella documentazione
- Cerca con una query breve fatta delle parole chiave del problema, non con la frase dell'utente.
- Se i risultati non c'entrano, riprova una volta con parole diverse. Se ancora non trovi nulla,
  dillo apertamente.
- Chiudi la risposta con "Fonti:", seguito da titolo e URL presi dal campo `sources` dei risultati.
